# cheating_detection_v1

Exam cheating detection from a classroom camera. Every examinee is tracked (YOLO + ByteTrack) and a
3.2 s crop of each person is classified once per second by an X3D-L video network into 4 classes:

| id | class | from CVAT labels |
|---|---|---|
| 0 | normal | normal time + hard negatives (use calculator, raise hand, arrange papers, ...) |
| 1 | looking | suspicious_looking |
| 2 | interaction | communicating, exchange_object (both people get the label) |
| 3 | phone_cheatsheet | using_phone/cheat_sheet |

`cheat_score = 1 - P(normal)` raises the alert; the most likely cheating class gives its type.
Two models share the same data, app and tools: **X3D-L** (default, recommended) and **TSM-R50** (alternative,
select it with `--config configs/tsm.yaml`).
This project is self-contained: its own code (`cheating_v1`), config, data, weights and results.

## Layout

```
cheating_detection_v1/
├── configs/default.yaml          X3D-L: every setting (paths, classes, clip cutting, model, training, app)
├── configs/tsm.yaml              TSM-R50: same settings, TSM model / weights / schedule
├── src/cheating_v1/
│   ├── __main__.py               python -m cheating_v1 <command>
│   ├── config.py                 YAML loading, --set overrides, path resolution
│   ├── data/cvat.py              CVAT 1.1 track reader
│   ├── data/prepare.py           extract videos, cut per-person clips, write train/val lists
│   ├── data/dataset.py           clip dataset, balanced sampler, GPU augmentation
│   ├── models/x3d.py             X3D (pytorchvideo)
│   ├── models/tsm.py             TSM-R50 (temporal shift on torchvision ResNet-50, OpenMMLab K400 init)
│   ├── models/registry.py        per-architecture frames / sampling / normalisation, build / save / load
│   ├── train.py                  fine-tuning (bf16, EMA, mixup, cosine LR, multi-view test)
│   ├── evaluate.py               clip-level evaluation
│   └── app/
│       ├── detector.py           real-time pipeline (YOLO, ByteTrack, X3D, smoothing, alerts)
│       ├── infer.py              video / webcam / RTSP front end
│       ├── eval_videos.py        end-to-end evaluation on full videos vs ground truth
│       ├── tune_thresholds.py    alert-threshold sweep from saved logs
│       └── calibrate_boxes.py    fit app.box_map for a camera
├── scripts/                      upload_to_instance.sh (your machine), setup_instance.sh (GPU machine)
├── data/raw/DOAN1/               original dataset (CVAT exports + task backups with the videos)
├── weights/
│   ├── x3d_l_v1_best.pt          trained X3D-L (default)
│   ├── tsm_r50_v1_best.pt        trained TSM-R50
│   └── pretrained/               TSM Kinetics-400 init (OpenMMLab)
└── outputs/reference/            logs and results of the shipped models
    ├── data/prepare_clips_hr.log clip counts per split / class
    ├── x3d_l/train/              train.log, history.json, final_val_multiview.json, args.json, TensorBoard
    ├── x3d_l/app_eval/           eval.log, summary.json, threshold sweep, per-window logs S07 / S08
    ├── x3d_l/demo/               annotated S07 / S08 excerpts (150 s) + events
    └── tsm_r50/train/            train.log, history.json, final_val_multiview.json, args.json, TensorBoard
```
`data/videos/` and `data/processed/` are generated by `prepare`.

## Run on a new GPU instance (e.g. Vast.ai, "PyTorch (Vast)" template)

```bash
# 1. on your machine (Git Bash on Windows): send code + weights, not the 5 GB dataset
bash scripts/upload_to_instance.sh <ssh_port> root@<ip> /workspace
# 2. on the instance: install, download DOAN1 from Google Drive (~3.7 GB, ~3 min), cut the clips (~6 min)
cd /workspace/cheating_detection_v1 && bash scripts/setup_instance.sh
# 3. use it
python -m cheating_v1 evaluate
```
- GPU memory: training X3D-L with `batch_size: 12` needs ~17 GB (RTX 3090 / 4090 / A5000 or larger). On a 12 GB card
  use `--set train.batch_size=6`. Inference and evaluation fit in ~4 GB.
- `train.workers: auto` uses the container CPU quota (Vast limits CPUs even when `nproc` shows the host count).
- On Vast `/workspace` is usually **not** a persistent volume: copy `outputs/` and new `best.pt` files back
  before destroying the instance (`scp -P <port> -r root@<ip>:/workspace/cheating_detection_v1/outputs/runs .`).
- Tested versions are pinned in `requirements-lock.txt`.

## Setup (own machine)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128   # match your CUDA
pip install -e .
```

## Commands

```bash
python -m cheating_v1 download                 # DOAN1 from Google Drive into data/raw (only if data/raw is empty)
python -m cheating_v1 prepare                  # data/raw -> data/videos + data/processed/clips_hr (~6 min)
python -m cheating_v1 train                    # outputs/runs/<run>/best.pt (~36 min on an RTX 3090)
python -m cheating_v1 evaluate                 # clip-level metrics of weights/x3d_l_v1_best.pt
python -m cheating_v1 infer --source exam.mp4 --out annotated.mp4 --events events.csv
python -m cheating_v1 infer --source 0 --show  # webcam; RTSP/HTTP URLs work too
python -m cheating_v1 eval-videos              # full S07 + S08 videos vs ground truth (~10 min)
python -m cheating_v1 tune                     # threshold sweep from the eval-videos logs
python -m cheating_v1 calibrate                # re-fit app.box_map (new camera angle)

# TSM-R50 instead of X3D-L: add --config configs/tsm.yaml to any command
python -m cheating_v1 train --config configs/tsm.yaml      # ~12 min on an RTX 3090
python -m cheating_v1 evaluate --config configs/tsm.yaml
python -m cheating_v1 infer --config configs/tsm.yaml --source exam.mp4 --out annotated_tsm.mp4
```
Any setting can be overridden: `--set train.epochs=15 app.thr_on=0.9 app.det_imgsz=1280`.
To use a newly trained model by default, copy its `best.pt` to `weights/x3d_l_v1_best.pt`.

## Results of the shipped models (val = S07 + S08, never trained on)

| | value |
|---|---|
| X3D-L, clip level, 3-view (450 clips) | cheat AUROC 0.946, recall 0.823, precision 0.936, macro-F1 0.748 |
| TSM-R50, clip level, 3-view (450 clips) | cheat AUROC 0.902, recall 0.758, precision 0.897, macro-F1 0.695 |
| X3D-L, full videos (24 min, 8766 windows) | window AUROC 0.921 |
| X3D-L alerts at thr 0.85 / 0.70, smooth 3, min 2 windows | 43 of 52 cheating events caught (83 %), 15.6 false alarms per person-hour |

TSM is weaker, mostly on phone / cheat sheet (8 sparse frames at 224 px), and has not been evaluated on full
videos (`eval-videos --config configs/tsm.yaml`). The epoch and the thresholds were chosen on S07 + S08, so these
numbers are optimistic. The models work on the DOAN1 room (6 people, high camera); on a different classroom they
need labelled data from that camera.
Throughput: ~40 fps on 1080p with 6 people (RTX 3090).
